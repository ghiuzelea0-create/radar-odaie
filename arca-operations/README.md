# Arca Operations — MVP

Dashboard operațional pentru Arca Interiors, construit cu Next.js 16, React 19, Tailwind CSS 4 și shadcn/ui.

## Funcționalități incluse

- indicatori CEO pentru venit, marjă, proiecte și capacitatea fabricii;
- tabel de proiecte cu filtre de stadiu și căutare;
- încărcarea secțiilor de producție și avertizare de capacitate;
- formular interactiv pentru o ofertă nouă;
- meniu responsive pentru desktop și mobil;
- interfață în limba română, adaptată activității Arca Interiors.

Datele afișate în acest MVP sunt demonstrative.

## Pornire locală

```bash
npm install
npm run dev
```

Aplicația va fi disponibilă la `http://localhost:3000`.

## Verificare

```bash
npm run lint
npm run build
```

Ambele verificări trec în versiunea livrată.
