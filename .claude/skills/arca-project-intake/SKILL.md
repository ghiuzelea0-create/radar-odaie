# arca-project-intake (DRAFT)

Problema: cererile intră incomplet → reluări, erori, timp pierdut.
Declanșator: proiect/ofertă nou(ă). Agent care îl folosește: arca-coordinator (intrare).

## Date minime de colectat
- Tip proiect (rezidențial/comercial/produs), locație și acces montaj.
- Corpuri/piese și cantități; cote (mm) sau PDF cotat + export DWG/DXF/IFC/OBJ.
- Materiale (PAL/MDF vopsit/masiv/metal/sticlă), finisaje, canturi.
- Feronerie preferată (Blum/Häfele) și nivel de dotare.
- Termen dorit, buget orientativ, monedă, TVA (inclus/exclus).

## Pași
1. Verifică ce e deja furnizat. 2. Cere DOAR ce lipsește (max 3 întrebări critice/rundă).
3. Marchează „DE VERIFICAT". 4. Predă pachetul complet la proiectare/costing.

## Rezultat & test
Fișă de intake completă, fără cote inventate. Test: costingul poate porni fără a mai reveni cu întrebări critice.
